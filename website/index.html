Questions

Which games work?

Any game with a LAN or system link mode. It connects consoles, not a particular game.

Which consoles?

PS4 and PS5 are tested. Other consoles with a LAN mode should work the same way but haven’t been tested yet.

Does every player need a PC?

Yes, a Windows 10 or 11 PC near their console.

Do I need to open ports?

No. Rooms connect directly between homes, and fall back to a relay when they can’t.

Will it lag?

Distance adds delay. Friends in the same region on good connections play smoothly.

Wi-Fi or Ethernet?

Wi-Fi is easiest: your PC creates a network for your console. It needs Wi-Fi that supports Windows Mobile Hotspot. A spare Ethernet port works too.

Does my console keep its Internet?

Yes, through your PC.

Is it safe?

Everything between players is encrypted, and only people with your room code can join.

Why install Npcap separately?

CODCONNECT needs it to reach your console, and its license doesn’t allow bundling it.

Windows warned me about the installer

It isn’t code-signed yet. Choose More info, then Run anyway. The source is on GitHub.

Is it free?

Yes. Free and open source, MIT license.

Get CODCONNECT

  1. Install Npcap
  2. Run the CODCONNECT installer
  3. Finish the SoftEther setup it opens
